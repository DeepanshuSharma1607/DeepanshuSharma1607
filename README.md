## 🚀 Featured Projects

**[AI-Powered Research Report Maker](https://github.com/DeepanshuSharma1607/Ai-Powered-Research-Report-Maker)**
4-agent pipeline (search → extraction → drafting → self-review) generating structured, source-backed research reports in ~60s, with a critic-chain self-review step. Deployed on AWS EC2 via Docker Compose (FastAPI + Streamlit).

**[EchoMind — AI-Powered Video Assistant](https://github.com/DeepanshuSharma1607/Ai-Powered-Video-Assistant)**
RAG-based assistant that transcribes YouTube videos, audio, and video files and answers natural-language questions with persistent conversation history. Per-session vector storage in ChromaDB; containerized with Docker.

**[IPL Match Win Predictor](https://live-ipl-win-predictor.streamlit.app)**
Ball-by-ball win probability model using engineered match-state features (RRR, pressure index, phase-of-innings) from 2008–2025 IPL data. XGBoost ensemble reaching 74.6% test accuracy / 0.73 ROC-AUC, deployed live on Streamlit.

**[BirdCLEF 2026 — Kaggle Competition](https://github.com/DeepanshuSharma1607/BirdCLEF-2026)**
Audio classification pipeline for 236 bird species using mel-spectrogram features and TensorFlow deep learning, achieving 0.64 AUC.
